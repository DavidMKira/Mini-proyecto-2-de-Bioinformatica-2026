# Mini-proyecto-2-de-Bioinformatica-2026
Este proyecto clasifica cinco tipos de cáncer a partir de perfiles de expresión de 20.531 genes obtenidos por RNA-Seq (dataset TCGA-PANCAN-HiSeq).
Clasificador bioinformático de tipos de cáncer basado en perfiles de expresión génica RNA-Seq.   Este repositorio aborda el obstáculo de la altísima dimensionalidad biológica (p ≫ n) utilizando el dataset TCGA-PANCAN-HiSeq. A partir de 801 muestras clínicas, el análisis procesa 20.531 genes para discriminar entre cinco variantes tumorales: BRCA, KIRC, COAD, LUAD y PRAD. El conjunto de datos presenta cero valores nulos y un desbalance de clases donde BRCA domina estadísticamente.   Extracción de Características y PCA
Proyectar 20.000 variables continuas a un plano bidimensional expone la topología subyacente de la expresión génica. Tras neutralizar las distorsiones de escala mediante MinMaxScaler, los componentes PC1 y PC2 capturan el 22.10% de la varianza total.   El cálculo de los vectores de carga aísla de inmediato a gene_1858 y gene_9175 como los motores geométricos principales de la separación ortogonal. Un biplot confirma visualmente la agrupación de los linajes tumorales.   Modelado Predictivo
Un Random Forest configurado con 100 estimadores y evaluación Out-Of-Bag (OOB) cambia el enfoque no supervisado por la discriminación de clases. El resultado es una precisión del 99.50%.   La matriz de confusión OOB registra apenas cuatro fallos en todo el dataset.   Al extraer la importancia de características del ensamble, el algoritmo supervisado prioriza un conjunto genético radicalmente distinto (gene_14092, gene_15987) al sugerido por PCA. La información biológica que optimiza la frontera de decisión predictiva no coincide con las direcciones de mayor varianza global.
